# Negative load for transactions API

negative load testing of my transactions API


## Test1 50 users/50 ramp up

Execute command from console

```
locust -f negativeblockload.py -u 50 -r 50 --run-time 1m --headless --host=http://18.222.141.251:8080

```
1. u - users

2. r - ramp up rate users/s

3. runtime 1m

### Conclusion:
6127 requessts per minute
avg latency 480 ms
error rate 0
